# 📊 Retail Sales Analysis Using PySpark

## Overview
This project analyzes the Online Retail dataset using Apache PySpark in Google Colab. It performs data cleaning, exploratory data analysis, Spark SQL aggregations, and visualization to identify sales trends and customer behavior.

## Technologies Used
- Apache Spark (PySpark)
- Python
- Google Colab
- Pandas
- Matplotlib

## Features
- Data Cleaning
- Missing Value Handling
- Monthly Sales Analysis
- Top Selling Products
- Customer Analysis
- Data Visualization
